# DomHub — Find & Register Your Perfect Domain

A single-page web app for exploring and registering domain names. Built with plain HTML, CSS, and JavaScript.

## Features

- 🔍 Domain search and availability checker
- - 📝 Blog, About, and Support pages
  - - 🔐 Sign In modal with animations
    - - 📱 Fully responsive design
     
      - ## Tech
     
      - Plain HTML5 + CSS3 + Vanilla JS. Zero dependencies. Built with Claude.
